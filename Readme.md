# Project Genesis

> **플레이어가 만드는 또 하나의 현실**
>
> *Another Reality Built by Players*

---

# 게임 소개

Project Genesis는 개발사가 모든 콘텐츠를 제공하는 기존 MMORPG와 달리,
플레이어가 직접 사회와 문화를 만들어가는 온라인 오픈월드 RPG이다.

개발사는 하나의 거대한 세계와 최소한의 규칙만 제공한다.

그 이후의 모든 이야기는 플레이어들이 직접 만들어 간다.

누군가는 상인이 되고,

누군가는 모험가가 되고,

누군가는 길드를 만들고,

누군가는 왕국을 세우며,

누군가는 전설이 된다.

Project Genesis는 제작된 이야기를 소비하는 게임이 아니라

플레이어가 직접 역사를 만들어가는 게임이다.

---

# 로그라인

퀘스트도 없고,

직업도 없으며,

정답도 없다.

세계를 살아가는 방법은 스스로 선택해야 한다."

# 게임 목표

Project Genesis의 목표는 플레이어가 제작자가 정해둔 목표를 따라가는게 아니라,

플레이어 스스로 사회를 만들어가는 가상의 세계를 구축하는 것이다.

게임은 시스템이 허용하는 범위내에서 유저의 플레이를 제한하지 않는다.

플레이어가 목표를 만든다.

게임은 직업을 제공하지 않고 플레이어가 직업을 자칭한다.

게임은 시스템적으로 길드시스템같은 편의사항을 제공하지 않고 플레이어가 조직을 만든다.

플레이어가 역사를 만들고 게임사는 해당 내용을 유튜브등에 업로드하여 기록을 남긴다.

---

## 2. 정보가 콘텐츠

튜토리얼이 없다.

아이템 설명도 없다.

몬스터 정보도 없다.

지도도 없다.

모든 정보는 탐험하거나 다른 플레이어에게 배우거나 커뮤니티를 통해 공유해야 한다.

시스템이 게임내에 존재하는지에 대해서만 공지를 통해 알린다.

업데이트를 통해 추가되는 시스템이 있다면 해당 시스템이 추가됐다고만 알린다.

시스템의 세부사항은 모두 플레이어가 각자 알아내야하고 버그가 없다면 기존의 세부사항은 수정하지 않는다.

---

## 3. 자유로운 역할 수행

직업 시스템이 존재하지 않는다.

누군가는

상인이 되고,

약사가 되고,

탐험가가 되고,

은행원이 되고,

용병이 된다.

이 역할은 시스템이 아닌

플레이어들의 인정으로 만들어진다.

---

## 4. 살아있는 운영

운영자는 단순히 서버를 관리하지 않는다.

플레이어들의 활동을 분석하고

필요한 이벤트를 개최하며

세상의 균형을 유지한다.

특정 보스 몬스터는

운영자가 직접 조작하여

매번 다른 전투를 제공한다.

---

## 5. 죽음의 의미

죽음은 단순한 패널티가 아니다.

플레이어는 신의 공간에서 자신의 여정을 돌아보고,

원한다면 새로운 삶을 시작할 수 있다.

# 개발 목표

Project Genesis는

'최대한 적은 시스템으로 최대한 많은 플레이어 경험을 만든다.'

라는 철학을 가진다.

개발사는 모든 콘텐츠를 제작하는 것이 아니라,

플레이어들이 새로운 이야기를 만들어갈 수 있는 환경을 제공하는 것을 목표로 한다.

# 기획 의도

최근의 MMORPG는 빠른 성장과 효율적인 플레이를 중심으로 설계되어 있다.

퀘스트를 따라가고, 정해진 장비를 맞추고, 반복적인 콘텐츠를 소비하는 방식이 일반적이다.

Project Genesis는 이러한 구조에서 벗어나고자 한다.

이 게임은 콘텐츠를 소비하는 게임이 아니라, 플레이어가 직접 콘텐츠를 만들어가는 세계를 목표로 한다.

플레이어가 만드는 이야기,

플레이어가 만드는 경제,

플레이어가 만드는 역사.

Project Genesis는 게임이 아닌 하나의 살아있는 사회를 만드는 것을 궁극적인 목표로 한다.
