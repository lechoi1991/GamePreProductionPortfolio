# Project Genesis

> **플레이어가 만드는 또 하나의 현실**
>
> *Another Reality Built by Players*

## 프로젝트 소개

**Project Genesis**는 플레이어가 단순히 퀘스트를 수행하는 MMORPG가 아니라,
직접 도시를 건설하고, 경제를 운영하며, 사회와 역사를 만들어가는
온라인 오픈월드 사회 시뮬레이션 RPG입니다.

## 게임 개요

|항목|내용|
|-|-|
|장르|온라인 오픈월드 사회 시뮬레이션 RPG|
|플랫폼|PC|  
|개발 목표|플레이어가 직접 사회와 역사를 만드는 세계|

## 프로젝트 목표

- 플레이어 중심의 사회 시스템 구현
- 협력과 창작 중심의 게임 경험
- 지속 가능한 플레이어 커뮤니티 구축
- Pay to Win 없는 공정한 서비스

## 핵심 특징

- 🏛️ 플레이어가 만드는 도시와 국가
- 💰 실제처럼 순환하는 경제 시스템
- ⚖️ 정치, 법률, 세금 시스템
- 📖 플레이어가 만드는 역사
- 🤝 협력 중심의 사회 구조
