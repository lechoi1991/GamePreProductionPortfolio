# 미니 시장 분석표

## 만들고자하는 게임 목표
    - 단순히 제작자가 아닌 게임의 일부가 되자
    - 전생류의 게임화
    - 유저의 선택에 의해 모든 것이 결정되는 세상
    - 중세 판타지 배경
    - 1인 1아이디 제한
    - 간헐적으로 게임 플레이시 게임화면 인증, 본인인증
    - 게임에서 본인의 현실정보를 공개할지 말지 선택

## 게임 장르 : 오픈월드

### 1. 이 장르를 좋아할 사용자
    - 예상 연령대: 10대 ~ 30대
    - 자주 플레이하는 플랫폼: PC
    - 좋아할 만한 이유: 협동과 경쟁을 통해서 자신의 목표를 달성하고 보상 취득

### 2. 유사 게임 3개
    - 게임 1: 스타시티즌
    - 게임 2: 알비온온라인
    - 게임 3: 엘더스크롤

### 3. 유사 게임에서 배울 점
    - 재미있는 점: 유저의 선택이 강제되지 않고 자율적으로 활동 가능
    - 불편한 점: 한번 플레이시에 장시간 
    - 우리 게임에 참고할 점: 방대한 월드와 세계관

### 4. 간단 SWOT
    - Strength 강점: 유저가 직접적으로 운영진과 소통가능
    - Weakness 약점: 자동화 하지 않은 요소에 의해 운영진의 업무 과부화
    - Opportunity 기회: AI가 도입되며 일자리 압박이 심해지고 여가에서도 수익창출이 되는 것들을 찾을 가능성이 있음
    - Threat 위협: 운영진의 개입이 과도하다고 생각하는 유저들이 있을 수 있음

# 사용자 페르소나와 수익 모델 정리

## 게임 가제 : Project Genecis

### 1. 대표 사용자 페르소나
    - 이름 : 최종화
    - 나이 : 만 35
    - 주로 쓰는 플랫폼 : PC
    - 하루 플레이 가능 시간 : 평일 3시간, 주말 8시간
    - 좋아하는 게임 : 리그오브레전드, MMORPG
    - 게임에서 기대하는 것 : 타 플레이어와의 관계형성, 수익창출
    - 싫어하는 것 : 잦은 버그, 유저의견 무시, 불활식한 상황에서 플레이어에게 증명 강요

### 2. 사용자 목표
    - 현실에서 해볼 수 없는 활동들을 통해 온라인 상에서 인간관계를 넓히고 수익 창출 및 사회활동에 도움이 되도록 함

### 3. 수익 모델
    - 선택한 수익 모델: 게임 내 요소에 대한 현금 판매, 유튜브에 게임현황을 업로드하여 수익창출
    - 이 모델을 선택한 이유: 게이머들이 낭만을 느끼게 하고 싶어서
    - 사용자가 부담스럽게 느낄 수 있는 지점: 자신의 정보나 활동이 외부에 공개되는 것
    - 부담을 줄이는 방법: 업로드를 위한 영상 촬영등을 할때는 미리 고지를 함

### 4. 한 문장 정리
    - 현실에서는 실천해 보지 못했던 새로운 자신을 만들어가는 과정을 통해 자신의 정체성을 탐구하고 정해둔 목표를 달성하여 성취감을 얻는다


# 유사 게임 콘텐츠 분석표

## 분석할 장르 : 오픈월드 
    - 유사 게임 A : 스타시티즌
    - 유사 게임 B : 러스트

### 1. 플레이어가 반복하는 행동
    - 게임 A : 새로운 지역 탐험, 함선 업그레이드, 자신만의 목표 추구
    - 게임 B : 생존을 위해 다른 플레이어들과 협동하거나 경쟁하며 파밍과 성장

### 2. 가장 큰 재미
    - 게임 A : 압도적인 그래픽과 디테일에서 오는 극상의 몰입감, 정해진 목표 없이 광활한 우주를 탐험하며 '또 다른 삶'을 사난 듯한 플레이어 중심의 자율성
    - 게임 B : 거친 환경과 예측 불가능한 타 유저와의 상호작용(협력, 배신, 약탈)에서 오는 팽팽한 생존 긴장감과 거점 건축/방어의 재미

### 3. 보상 구조
    - 게임 A : 다양한 활동(수송, 채굴, 무역 등)으로 획득하는 재화, 더 나은 성능의 함선/장비, 플레이어 조직 내에서의 사회적 입지 및 명성
    - 게임 B : 생존 자원 및 희귀 파밍 아이템/총기, 내구도와 규모를 확장한 안전한 거점(기지), 타 유저와의 전투 및 약탈 성공을 통한 정복감

### 4. 불편하거나 아쉬운 점
    - 게임 A : 지나치게 높고 어려운 초기 진입 장벽(복잡한 조작/시스템), 극심하게 긴 개발 기간과 지속적인 버그/안정성 문제
    - 게임 B : 주기적인 서버 초기화(Wipe)로 인한 장기적 성과의 허무함, 초보자를 향한 무차별적 PK/약탈(Griefing)로 인한 신규 유저 정착의 어려움

### 5. 우리 게임에 가져올 점
    - 스타시티즌의 몰입감과 자율 탐험 : 개발사가 퀘스트를 강요하지 않고, 플레이어 스스로가 세계를 탐험하며 개인/집단의 목표를 설정하도록 유도하는 플레이 구조
    - 러스트의 상호작용과 긴장감 : 시스템이 모든 안전을 보장하지 않기에 발생하는 플레이어 간의 자발적 협동, 역할 분담, 그리고 긴장감 넘치는 정치·사회적 상호작용

### 6. 우리 게임에서 피할 점
    - 복잡하고 난해한 시스템으로 인한 높은 진입 장벽 : 현실적인 몰입감은 유지하되, 지나치게 복잡한 시스템 조작보다는 단순하고 직관적인 규칙 위에서 사회가 형성되도록 유도
    - 반복적인 서버 초기화(Wipe) : 생존 자체에 집중되어 성과가 리셋되는 구조를 피하고, 장기적인 역사와 사회 구조가 축적되는 장기 운영형 월드 구축
    - 보호 장치 부재로 인한 무차별적 사회 붕괴 : 최소한의 안전지대(성역)와 기본 인프라를 제공하여, 트롤링이 발생하더라도 그것이 하나의 정교한 스토리/콘텐츠로 변모할 수 있는 가이드라인 확보

### 7. 우리 게임의 핵심 재미 한 문장
    - "아무런 정답도 없는 미지의 세계에서, 플레이어들이 직접 협력하고 경쟁하며 자신만의 사회와 역사를 만들어가는 샌드박스적 자유"
