# 미니 시장 분석표

## 만들고자하는 게임 목표
    - 단순히 제작자가 아닌 게임의 일부가 되자
    - 전생류의 게임화
    - 유저의 선택에 의해 모든 것이 결정되는 세상
    - 중세 판타지 배경
    - 1인 1아이디 제한
    - 간헐적으로 게임 플레이시 게임화면 인증, 본인인증
    - 게임에서 본인의 현실정보를 공개할지 말지 선택

## 게임 장르 : 오픈월드

### 1. 이 장르를 좋아할 사용자
    - 예상 연령대: 10대 ~ 30대
    - 자주 플레이하는 플랫폼: PC
    - 좋아할 만한 이유: 협동과 경쟁을 통해서 자신의 목표를 달성하고 보상 취득

### 2. 유사 게임 3개
    - 게임 1: 스타시티즌
    - 게임 2: 알비온온라인
    - 게임 3: 엘더스크롤

### 3. 유사 게임에서 배울 점
    - 재미있는 점: 유저의 선택이 강제되지 않고 자율적으로 활동 가능
    - 불편한 점: 한번 플레이시에 장시간 
    - 우리 게임에 참고할 점: 방대한 월드와 세계관

### 4. 간단 SWOT
    - Strength 강점: 유저가 직접적으로 운영진과 소통가능
    - Weakness 약점: 자동화 하지 않은 요소에 의해 운영진의 업무 과부화
    - Opportunity 기회: AI가 도입되며 일자리 압박이 심해지고 여가에서도 수익창출이 되는 것들을 찾을 가능성이 있음
    - Threat 위협: 운영진의 개입이 과도하다고 생각하는 유저들이 있을 수 있음

# 사용자 페르소나와 수익 모델 정리

## 게임 가제 : Project Genecis

### 1. 대표 사용자 페르소나
    - 이름 : 최종화
    - 나이 : 만 35
    - 주로 쓰는 플랫폼 : PC
    - 하루 플레이 가능 시간 : 평일 3시간, 주말 8시간
    - 좋아하는 게임 : 리그오브레전드, MMORPG, 비쥬얼노벨
    - 게임에서 기대하는 것 : 타 플레이어와의 관계형성, 수익창출
    - 싫어하는 것 : 잦은 버그, 유저의견 무시, 불활식한 상황에서 플레이어에게 증명 강요

### 2. 사용자 목표
    - 현실에서 해볼 수 없는 활동들을 통해 온라인 상에서 인간관계를 넓히고 수익 창출 및 사회활동에 도움이 되도록 함

### 3. 수익 모델
    - 선택한 수익 모델: 게임 내 요소에 대한 현금 판매, 유튜브에 게임현황을 업로드하여 수익창출
    - 이 모델을 선택한 이유: 게이머들이 낭만을 느끼게 하고 싶어서
    - 사용자가 부담스럽게 느낄 수 있는 지점: 자신의 정보나 활동이 외부에 공개되는 것
    - 부담을 줄이는 방법: 업로드를 위한 영상 촬영등을 할때는 미리 고지를 함

### 4. 한 문장 정리
    - 현실에서는 실천해 보지 못했던 새로운 자신을 만들어가는 과정을 통해 자신의 정체성을 탐구하고 정해둔 목표를 달성하여 성취감을 얻는다
